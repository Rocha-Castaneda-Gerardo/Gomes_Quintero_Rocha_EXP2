# Sistema de Gestión de Videojuegos (Juegoteca)

Sistema de consola en **C# · .NET 8** para registrar jugadores, crear colecciones de videojuegos,
buscar por título, ordenar por horas de juego y exportar las colecciones a un archivo `.txt`.
Desarrollado de forma distribuida en GitHub y validado con pruebas unitarias **xUnit**.
